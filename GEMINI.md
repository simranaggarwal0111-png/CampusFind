# Antigravity Instructions for CampusFind

## Response & Communication Formatting
- Never format local file paths or code symbols as clickable `file://` URLs or downloadable file artifacts.
- Always refer to file paths, variables, and code symbols in plain inline backticks (e.g., `backend/src/config/db.js`).
- Keep chat responses clean and direct without triggering file attachment pills (`[Open] [Get]`) or task log attachments.
